# Learning cheatsheet

| Command | Action |
| --- | --- |
| `study start japanese` | Journal, practice pane, initial Firefox/Anki launch |
| `study start programming` | Exercise journal and practice pane |
| `study start reading` | Reading journal and practice pane |
| `study start general` | General study journal and practice pane |
| `study status` | Show the selected mode |
| `study stop` | Clear the active mode and retain work |
| `study resources` | Open the learning Firefox profile and Yomitan guide |
| `study input` | Toggle the configured Fcitx input method |

Choose Mozc in Fcitx settings before toggling Japanese input. Type rōmaji;
`Space` converts candidates and `Enter` commits. Toggle back before Vim commands.

Journals live in `~/Documents/Learning/<mode>/journal.md`. End a session by
recording what you learned, remaining questions, and the next useful action.
See [Learning sessions](../learning.md) for Yomitan/Anki setup and backup paths.
